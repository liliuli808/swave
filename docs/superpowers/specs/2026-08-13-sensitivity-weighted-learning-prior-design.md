# 灵敏度加权学习先验混合反演设计

日期：2026-08-13  
状态：已确认，待实施

## 1. 目标

在现有直接监督反演和基于正演代理的 L-BFGS-B 反演之间增加一个可审计的混合方法：
把三种子监督反演集成输出作为逐样本学习先验，并根据频散对每层介质的平均灵敏度构造
逐层先验权重。低灵敏度层受到更强的学习先验约束，高灵敏度层保留更多由当前观测修正
监督预测的自由度。

交付同时覆盖：

1. 代码、配置、测试和可恢复实验产物；
2. 报告方法章新增第 2.7 节；
3. 在监督直接反演结果之后新增第 7 节混合反演实验，原讨论、结论和可复现性章节顺延；
4. 在生产混合实验尚未完成时明确标注待运行，不填入推测数值。

## 2. 信息隔离与输入身份

- 直接监督反演仍只用 0--79 训练折拟合，80--84 验证折选择检查点；三个最佳检查点
  固定后才可作为学习先验生成器。
- 混合反演的先验强度只在 80--84 验证折的确定性分层子集上选择。
- 85--89 测试折用于混合方法的独立最终检查；90--99 反演保留折用于与现有
  L-BFGS-B 和监督反演做同样本比较，不参与权重公式或超参数选择。
- 混合实验身份必须绑定数据清单、正演代理检查点、三个有序监督检查点及其运行身份、
  源码摘要、验证样本 ID 摘要、灵敏度定义、权重上下限、先验强度候选集合和最终选择。
  任一身份不一致都拒绝恢复或汇总。

生产运行需要三个 `seed-<N>-best.pt`。当前仓库只归档了监督评估 JSON、训练历史和日志，
未归档最佳权重，因此实现与小夹具验证可以在当前环境完成，生产混合数值必须在三个最佳
检查点可用后运行。

## 3. 监督先验

对当前样本的观测频散和有效掩码执行与监督训练完全相同的预处理：去掉 0.5 Hz 列，
无效值使用训练折统计填充，再用训练折输入统计归一化。三个最佳监督网络各输出一个
20 层 Vs，等权平均得到

\[
\mathbf v^{\mathrm{sup}}=\frac{1}{3}\sum_{k=1}^{3}
\mathbf v^{\mathrm{sup},k}.
\]

学习先验目标只截断到全局物理范围 \([0.3,2.6]\) km/s，不使用当前样本真值，也不把
监督结果变成硬边界或优化初值。这样监督信息在混合实验中只通过新增正则项进入目标函数。

## 4. 灵敏度与逐层权重

在 \(\mathbf v^{\mathrm{sup}}\) 处用 float64 正演代理计算完整雅可比。对第 \(i\) 层，
定义模态权重和有效掩码加权的无量纲平均绝对灵敏度：

\[
s_i =
\frac{
\sum_{m,f} I_{m,f}w_m
\left|\frac{v_i^{\mathrm{sup}}}{F_{m,f}}
\frac{\partial F_{m,f}}{\partial v_i}\right|
}{
\sum_{m,f} I_{m,f}w_m
}.
\]

其中 \(I_{m,f}\) 是当前样本有效掩码，\(w=(4,1,1,1)\) 与数据失配项一致。灵敏度只在
有限、有效且相速度绝对值高于数值安全阈值的单元上求均值；任何一层没有可用灵敏度、
出现非有限雅可比或全部灵敏度为零时，该样本失败并记录明确失败码，不以默认常数静默替代。

先验权重与灵敏度成反比：

\[
r_i=\frac{1}{s_i+\epsilon_s},\qquad
\omega_i=\operatorname{clip}(c r_i,\omega_{\min},\omega_{\max}),\qquad
\frac{1}{20}\sum_i\omega_i=1.
\]

标量 \(c\) 由单调二分求解，使权重均值严格为 1，同时满足配置的上下限。默认
\(\omega_{\min}=0.25\)、\(\omega_{\max}=4\)；\(\epsilon_s\) 按样本平均灵敏度的固定
小比例构造并写入身份。由此低灵敏度层的学习先验权重大，高灵敏度层权重小，且全局
先验强度 \(\lambda_p\) 在样本之间保持可解释。

雅可比和权重对每个样本只在优化前计算一次，在 L-BFGS-B 迭代中保持不变，从而保留
平滑、确定的目标函数并避免每轮重新构造二阶计算图。

## 5. 混合目标函数

新目标为

\[
J_{\mathrm{hybrid}}(\mathbf v)=
J_{\mathrm{disp}}(\mathbf v)
+\frac{\lambda_s}{20}\|R(\mathbf v-\mathbf v_{\mathrm{ref}})\|_2^2
+\frac{\lambda_p}{20}\sum_{i=1}^{20}
\omega_i(v_i-v_i^{\mathrm{sup}})^2.
\]

- `J_disp`、模态权重、有效掩码、正演代理和 autograd 梯度与现有 L-BFGS-B 完全一致；
- `lambda_s = 0.01` 和自适应一阶差分矩阵 `R` 保持现有设置；
- `lambda_p` 是唯一新增的全局强度超参数；逐层相对系数完全由灵敏度权重确定；
- 优化仍从现有观测构造的参考模型开始，但使用全局物理边界
  \([0.3,2.6]\) km/s，而不是参考模型 \(\pm0.35\) km/s 的窄边界；
- 直接监督输出不作为初值、硬边界或停止条件。

结果必须分别保存数据失配、光滑正则、学习先验正则和总目标，保证可以核对四项之和与
分析先验贡献。

## 6. 对照与超参数选择

第 7 节至少包含以下四种方法：

1. 已有窄边界 L-BFGS-B 基线；
2. 全局物理边界、没有学习先验的 L-BFGS-B 控制组；
3. 全局物理边界、灵敏度加权学习先验的混合 L-BFGS-B；
4. 三种子直接监督反演。

第 2、3 组使用相同参考初值、全局边界、优化器、迭代上限和数据，唯一差别为
`lambda_p = 0` 或验证选出的正值，因此可以区分放宽边界与学习先验的贡献。第 1 组保留
既有产物，不重写历史结果。

`lambda_p` 从配置的对数候选集合中选择。80--84 验证折按四个模型族确定性抽取等量
样本，在 clean 和 noise_1pct 两种情景上运行；用两种情景、全部样本和全部层的 Vs MAE
平均值作为唯一选择指标。并列时选更小的 `lambda_p`。选定值及每个候选的完整验证指标
写入不可变调参产物，随后才可启动测试折和反演保留折。

## 7. 实验产物与报告

混合结果写入独立目录，不能与现有 `results/inversion` schema-v3 产物混合。产物至少保存：

- 样本 ID、模型族、噪声情景和成功/失败诊断；
- 参考模型、监督先验、恢复模型和逐层真值联接前的身份；
- 20 层灵敏度与先验权重；
- 观测、代理重构、有效掩码；
- 初始/最终总目标、数据失配、光滑项、学习先验项、迭代数和函数求值数；
- 调参身份、检查点摘要、源码摘要和确定性作业清单。

第 2.7 节介绍监督先验、无量纲灵敏度、逆灵敏度权重和混合目标。新增第 7 节依次报告：

1. 验证折 `lambda_p` 选择；
2. 各层灵敏度均值和先验权重分布；
3. 四种方法在同样本上的总体、分族和逐层 Vs MAE/RMSE/P95；
4. clean/noise_1pct 稳健性、频散重构误差和优化代价；
5. 对“合成分布学习先验”信息优势及分布外风险的限制说明。

生产产物不可用时，第 7 节只给出已实现的方法、运行命令和待运行状态，不复用不匹配的
旧结果，也不根据监督单独结果推测混合反演数值。摘要、讨论、结论和产物清单只在正式
混合结果生成并校验后更新定量结论。

## 8. 错误处理与验证

自动化测试覆盖：

1. 线性玩具正演的解析雅可比与无量纲平均灵敏度；
2. 模态权重、缺失掩码和频率裁剪只影响预期单元；
3. 低灵敏度层获得更大权重，20 层权重均值为 1 且满足上下限；
4. 混合目标值和 autograd 梯度与解析二次项一致；
5. `lambda_p = 0` 与全局边界控制目标完全一致；
6. 监督检查点缺失、身份不一致或非有限预测立即失败；
7. 调参只读取验证折，最终比较不反向影响检查点或 `lambda_p`；
8. 分片恢复、源码/配置身份不一致和结果四项求和校验；
9. 相关测试、完整 pytest、Ruff、`git diff --check` 和报告 XeLaTeX 编译。

生产验收还要求三个监督最佳检查点、正演检查点和数据清单全部可用，并在报告中记录实际
命令、产物路径与校验摘要。
