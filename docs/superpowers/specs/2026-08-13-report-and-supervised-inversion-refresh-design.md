## 3. 固定数据协议

所有任务统一使用 `sample_id % 100`：

| 余数 | 集合 | 用途 |
| --- | --- | --- |
| 0--79 | train | 网络训练、输入/输出归一化、无效频点填充值统计 |
| 80--84 | validation | 检查点选择和早停 |
| 85--89 | test | 正演代理及监督反演的最终测试评估 |
| 90--99 | inversion | 仅用于基于代理的反演实验 |

检查点必须保存 `split_policy = "mod100-v2-80-5-5-10"`、数据集配置哈希、规范
数据集清单 SHA-256、训练样本身份摘要、网络配置和归一化数组。加载、恢复和评估时
任一身份不一致均报错。测试集不得用于训练、早停、超参数选择或种子选择。

## 4. 数据集审计

新增流式审计工具，逐分片读取 `data/production`，输出机器可读 JSON。审计包括：

1. 校验完整 manifest、100 个分片及其 SHA-256；
2. 校验 1,000,000 个 `sample_id` 唯一、连续且四折互斥；
3. 对每条 20 维 `Vs` 的原始 float32 字节计算摘要，统计全数据和跨折的精确重复；
4. 对每条完整物理记录（模型类别、Vs、Vp、密度、频散与掩码）计算摘要，统计精确
   重复记录；
5. 由 `(seed, sample_id, retry_count)` 重建确定性地质模型，逐条核对模型类别、Vs、
   Vp 和密度；
6. 统计四类模型的地质规则：正常背景随深度不减；低速异常为目标深度范围内连续
   1--3 层负异常；高速异常为连续 1--2 层正异常；耦合异常为 1 层高速后紧邻连续
   2--3 层低速；所有异常相对背景幅度至少 5%，所有速度和 Brocher 派生物性均在
   合法范围内；
7. 报告各族数量、异常层数、位置和对比度范围，并明确区分“代码规则全部通过”和
   “这些合成规则是简化的一维地质先验，不能替代实测地质验证”。

精确查重的定义是数组值逐位相同；不把数值接近但物理上不同的模型判作重复。

## 6. 监督直接反演

### 6.1 网络与输入

保留原监督基线的可比较结构：4 模态乘 119 个频点（去掉 0.5 Hz 列）展平为 476 维，
经 1024 宽度、4 个 Pre-LN 残差块的 MLP 输出 20 层 Vs。无效频点使用训练折逐
`(模态, 频点)` 均值填充；若训练折某单元全无效，则使用该模态所有有效训练值均值。
输入和输出均仅使用训练折统计做 z-score。

### 6.2 训练与选择

- 随机种子固定为 0、1、2；每个种子至多 150 轮；
- AdamW，学习率 `1e-3`，权重衰减 `1e-4`，批量 8192；
- CosineAnnealingLR；Huber 损失；验证集物理 Vs MAE 作为唯一检查点选择指标；
- GPU 支持 bf16 autocast；数据加载不能要求把全部百万样本同时驻留 GPU；
- 每个种子独立保存最佳检查点和训练历史；最终预测为三个最佳检查点的等权平均；
- 训练结束后一次性评估 85--89 测试折，生成总体、四模型族、逐层 MAE/RMSE/R2、
  P95 和样本数，以及集成相对单种子的验证集变化。

训练代码在 CPU 上用小型 HDF5 夹具验证；正式 3 种子训练仅通过交付命令在 GPU 主机
运行。本阶段绝不把旧监督检查点数值当作新协议结果。
