# 反演实验与四集合数据协议设计

日期：2026-08-02  
状态：已确认，待实施

## 1. 目标

在现有 `swave-forward` 正演求解器和四头神经网络代理之上，增加一套与 Pan、Wang 和 Chen（2026）反演思路一致的数值实验流程：

1. 将一百万条确定性样本严格划分为训练集、验证集、测试集和反演实验集；
2. 使用反演实验集的频散曲线，通过带边界的 L-BFGS-B 优化恢复固定 20 层的剪切波速度 `Vs`；
3. 使用数据失配、垂向平滑正则化、多初始模型和统计聚合控制非唯一性；
4. 分别评估无噪声和 1% 相对高斯噪声；
5. 输出可恢复、可审计、可在单机或集群执行的实验结果和图表。

本设计不训练独立的“频散曲线到 `Vs`”反演网络，也不把真实 `Vs` 用作初始模型或优化约束。真实 `Vs` 只能在反演完成后用于评价。

## 2. 数据划分与隔离

### 2.1 固定划分

所有划分由一个公共函数根据 `sample_id % 100` 决定：

| 余数 | 集合 | 比例 | 用途 |
| --- | --- | ---: | --- |
| 0–79 | `train` | 80% | 网络参数训练和归一化统计 |
| 80–84 | `validation` | 5% | 检查点选择 |
| 85–89 | `test` | 5% | 正演代理最终评价 |
| 90–99 | `inversion` | 10% | 独立反演实验 |

四个集合继续使用原 HDF5 分片，不复制样本。读取器只保存所选行的索引。划分逻辑不得分散在训练、绘图和反演代码中。

### 2.2 防止泄漏

- 输入和目标归一化只根据 `train` 计算。
- `validation` 只用于检查点选择。
- `test` 只用于正演代理的最终误差。
- `inversion` 不参与训练、早停、超参数选择或正演模型选择。
- 反演器只接收频散曲线、有效掩码、频率、模态和公开的模型边界。
- 报告器在优化结束后，才按 `sample_id` 读取真实 `Vs` 并计算误差。

检查点必须记录划分协议标识 `split_policy = "mod100-v2-80-5-5-10"`。缺少该标识或使用旧 `90/5/5` 协议的检查点不得用于新反演实验。

## 3. 反演数学设计

### 3.1 模型参数

反演变量为固定深度网格上的 20 个 `Vs`：19 个厚度为 0.1 km 的有限层，以及从 1.9 km 开始的半空间。`Vp` 和密度不独立反演；它们仍由数据集配置中的经验关系从 `Vs` 导出。

全局物理范围为：

\[
0.3 \le V_{S,j} \le 2.6\ \mathrm{km/s}.
\]

### 3.2 参考初始模型

参考初始模型只从当前噪声场景下的观测基阶频散曲线构造：

1. 对每个有效基阶数据点计算波长 `wavelength = c / f`；
2. 使用论文中的近似关系 `depth = wavelength / 3` 和 `Vs = 1.1 * c`；
3. 按深度排序并合并重复深度；
4. 线性插值到 20 层固定深度；
5. 使用权重 `[0.25, 0.5, 0.25]` 的三点滤波执行两次平滑，端点采用反射扩展；
6. 将结果裁剪到全局 `Vs` 范围。

如果有效基阶点不足两个，反演应记录 `insufficient_fundamental_data`，不得读取真实 `Vs` 作为回退。

每层的局部边界由参考模型和 `vs_width` 共同给出。默认 `vs_width = 0.7 km/s`：

\[
l_j=\max(0.3,V_{S,\mathrm{ref},j}-0.35),\qquad
u_j=\min(2.6,V_{S,\mathrm{ref},j}+0.35).
\]

### 3.3 目标函数

在物理单位 km/s 下最小化：

\[
\Phi(V_S)=
\sum_{m=0}^{3}\frac{w_m}{N_m}
\sum_{i\in\mathcal{V}_m}
\left[c_{\mathrm{pred}}(V_S,f_i,m)-c_{\mathrm{obs}}(f_i,m)\right]^2
+\frac{\lambda}{20}\left\|L(V_S-V_{S,\mathrm{ref}})\right\|_2^2.
\]

其中 `V_m` 是模态 `m` 的有效频率集合，`N_m` 是其大小。没有有效点的模态不参与目标函数。默认模态权重为 `[4, 1, 1, 1]`，默认 `lambda = 1e-2`。

默认正则化采用 QEDispInv 的自适应一阶形式。令

\[
a=0.1\max_j |V_{S,\mathrm{ref},j+1}-V_{S,\mathrm{ref},j}|,
\qquad
q_j=\frac{a}{a+|V_{S,\mathrm{ref},j+1}-V_{S,\mathrm{ref},j}|},
\]

则差分矩阵第 `j` 行的非零项为 `[q_j, -q_j]`。当参考模型为常数、`a = 0` 时，权重统一回退为 1。配置也可选择普通一阶差分，但正式实验使用自适应形式。

### 3.4 优化与梯度

- 使用 `scipy.optimize.minimize(method="L-BFGS-B")` 实施严格边界约束。
- 默认最大迭代数为 100，目标函数相对变化停止阈值为 `1e-5`。
- 正演代理保持 `eval()`，但不进入 `torch.inference_mode()`；目标函数对 `Vs` 的梯度通过 PyTorch 自动微分获得。
- 自动微分得到的是正演代理雅可比，替代论文中的物理敏感度核。这是为了把已训练的正演代理用于反演，同时保留论文的目标函数、边界、正则化和优化器结构。
- 每次返回给 SciPy 的目标值和梯度必须来自同一次前向/反向计算，并使用双精度 NumPy 接口。
- 优化过程中任何非有限目标值、梯度或越界结果均标记失败，不得静默填充值。

### 3.5 多初始模型与统计

深度实验的第一个初始模型是参考模型。其余 99 个模型通过确定性的平滑高斯扰动生成：随机场经过与参考模型相同的三点滤波两次，缩放到局部边界宽度后加到参考模型，并裁剪到边界。

随机种子由全局种子、`sample_id`、噪声场景和初始模型编号共同派生。完成 100 次反演后：

1. 去除失败结果；
2. 使用目标函数值的 1.5 倍四分位距规则去除失配异常值；
3. 在每个深度计算 `Vs` 中位数、P10 和 P90；
4. 中位模型作为该样本的代表反演结果。

如果有效解少于配置要求的最小值（正式配置默认为 20），样本标记为 `insufficient_valid_solutions`，但仍保留所有诊断信息。

## 4. 噪声设计

每条反演样本运行两种场景：

- `clean`：直接使用数据集频散曲线；
- `noise_1pct`：仅对有效数据点应用

\[
c_{\mathrm{noisy}}=c_{\mathrm{obs}}(1+0.01\epsilon),
\qquad \epsilon\sim\mathcal{N}(0,1).
\]

噪声随机种子由全局种子和 `sample_id` 派生。无效单元保持无效，不加噪、不补零、不插值。报告中必须将两种场景分开，并提供误差退化量。

## 5. 两级实验

### 5.1 全量总体实验

对 `inversion` 集全部 100,000 条样本运行参考初始模型的一次 L-BFGS-B 反演，并分别执行 `clean` 与 `noise_1pct`。该实验用于获得总体分布和按地质模型类别分层的稳定统计。

记录内容包括：

- `sample_id`、模型类别、噪声场景；
- 是否收敛、状态码、失败原因、迭代次数和函数调用次数；
- 初始和最终目标函数、数据项与正则项；
- 参考模型和反演 `Vs`；
- 代理模型重构频散误差。

### 5.2 论文式深度实验

从 `inversion` 集的 `NORMAL`、`LOW`、`HIGH` 和 `COUPLED` 四类中，按最小 `sample_id` 的稳定顺序各选择 100 条，共 400 条。若任一类别不足 100 条，配置校验应失败并报告缺少数量。

每条样本执行 100 个初始模型，并分别运行两种噪声场景。除代理模型指标外，还使用原始 Python Dunkin 数值正演器的 `quadratic` 策略，在原数据频率网格上对中位反演模型重新计算四模态频散曲线，以检验结果是否满足真实物理正演，而不是只利用代理误差获得低目标函数。物理复算误差只在观测与复算结果均有效的单元上统计，并单独报告复算缺失率。

## 6. 指标与图表

### 6.1 数值指标

总体、噪声场景、模型类别和深度层级均应报告：

- `Vs` MAE、RMSE、平均相对误差和 P95 绝对误差；
- 每层 `Vs` MAE、偏差和覆盖率；
- 代理频散曲线按模态的 MAE、RMSE 和 P95；
- 深度实验物理数值正演按模态的 MAE 和 RMSE；
- P10–P90 区间对真实 `Vs` 的覆盖率和平均区间宽度；
- 优化收敛率、失败原因分布、迭代次数和函数调用次数；
- 从 `clean` 到 `noise_1pct` 的指标退化。

### 6.2 图表

报告至少生成：

1. 按深度的 `Vs` MAE 和偏差曲线；
2. 四类模型在两种噪声场景下的误差箱线图；
3. 各类代表样本的真实 `Vs`、参考模型、反演中位数和 P10/P90 剖面；
4. 同一代表样本的观测、代理重构和物理数值正演重构四模态频散曲线；
5. 初始与最终失配、收敛率和迭代次数分布。

正式报告不得把未运行的配置或缺失结果显示为零。

## 7. 接口和配置

新增配置文件 `configs/inversion.toml`，包含：

- 数据集、检查点和输出目录；
- 模态权重、`lambda`、正则化类型；
- `vs_width`、迭代上限和停止阈值；
- 全局种子、噪声场景；
- 深度实验每类样本数、初始模型数和最少有效解数量；
- CPU worker 数和集群任务分配参数。

新增命令：

```text
swave invert --config configs/inversion.toml --experiment full
swave invert --config configs/inversion.toml --experiment deep
swave invert --config configs/inversion.toml --experiment both
swave inversion-report --results-dir results/inversion
```

命令行可覆盖 `dataset-dir`、`checkpoint`、`output-dir`、`device`、`workers`、`task-index` 和 `task-count`。配置解析后必须重新验证完整配置，未知键不得静默忽略。

## 8. 结果格式、恢复与并行

### 8.1 身份与清单

结果目录包含一个清单，绑定：

- 数据集配置哈希；
- 检查点 SHA-256；
- 划分协议；
- 完整反演配置哈希；
- 软件版本和创建时间；
- 预期结果分片及完成状态；
- 每个结果文件的 SHA-256。

任何身份不一致均拒绝恢复，避免将不同实验混在同一目录。

### 8.2 原子写入和断点续跑

结果按输入 HDF5 分片和噪声场景组织。每个结果先写入进程专属临时路径，关闭并校验数据集、形状、类型、样本标识及有限性后再原子重命名。重启时只跳过清单与校验均通过的完成分片。

单个样本失败时记录状态并继续该分片；分片结构损坏、样本身份不匹配或配置冲突则终止任务。

### 8.3 并行

- 单机 CPU 使用 `workers` 按样本并行，每个进程独立加载只读检查点。
- 集群使用 `task-index` 和 `task-count` 按结果分片取模分配，任务集合互斥且并集覆盖全部分片。
- CUDA 默认单进程，避免多个进程争用同一设备；集群多 GPU 由外部调度器为每个任务分配独立可见设备。
- 无论 worker 数或任务数如何变化，样本、噪声和初始模型均保持确定性。

## 9. 代码边界

计划新增或调整以下职责边界：

- 数据划分模块：唯一负责 `sample_id` 到集合的映射；
- HDF5 数据读取器：支持新的 `inversion` 集合；
- 反演配置：校验论文式优化参数和实验规模；
- 反演目标模块：参考模型、边界、噪声、目标函数和自动微分梯度；
- 反演运行器：单样本、多初始模型、分片、并行和恢复；
- 反演报告模块：读取真实 `Vs`、计算指标并生成图表；
- CLI：只负责参数解析、配置覆盖和调用工作流。

反演目标模块不得依赖报告模块，确保优化路径无法访问真实 `Vs`。

## 10. 测试和验收

自动测试必须覆盖：

1. 四集合互斥、并集完整，100 个余数严格得到 80/5/5/10；
2. 训练归一化和检查点只使用新训练集；
3. 旧划分协议检查点被拒绝；
4. 参考模型只依赖基阶频散数据，并满足全局范围；
5. 多初始模型和 1% 噪声对相同种子完全可复现；
6. 目标函数自动微分梯度与有限差分在容差内一致；
7. L-BFGS-B 输出始终满足逐层边界；
8. 模态权重、有效掩码和正则化项计算正确；
9. 异常值剔除和 P10/P50/P90 统计正确；
10. 损坏分片、配置冲突和中断恢复得到预期行为；
11. 集群任务分配无重叠且无遗漏；
12. 一个小型端到端夹具能完成训练检查点加载、反演、物理复算和报告生成。

当前六核 CPU 环境只运行单元测试和小规模端到端验证。正式一百万样本生成、训练、十万条全量反演和 400 条多初始模型实验由用户在另一台计算机运行。只有正式产物完整且通过清单校验后，才能报告正式反演效果。

## 11. 已知风险与控制

- **代理误差被优化利用**：深度实验必须使用原始 Dunkin 求解器复算中位模型。
- **反演非唯一性**：采用参考模型、边界、平滑正则化、多初始模型及 P10/P90，而不只报告单一最优解。
- **计算量过大**：使用两级实验、结果分片、断点续跑和集群任务分配。
- **旧检查点泄漏**：检查点强制记录并校验新划分协议。
- **高阶模态缺失**：全程保留有效掩码，只对存在的数据计算失配。
- **固定 20 层与论文随机分层不同**：保留项目规定的固定 20 层参数化；通过随机平滑初始 `Vs` 探索多解，不改变代理网络输入维度。
